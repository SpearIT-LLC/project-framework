# Framework Workspace

**Type:** application
**Purpose:** Source tree of the next SpearIT Framework, built fresh per
[ADR-009](../../project-hub/research/adr/009-workspace-model-and-fresh-build-in-place.md).

The framework IS the plugin: `spearit-framework-dev` on the dev channel, publishing
as `spearit-framework` at graduation. Versions are plain semver — the `0.x` series
is the dev series; the `-dev` plugin name is the channel marker, never the version
(no `-dev<n>` suffixes, unlike the old plugins). Distribution is a marketplace install; repo
structure (`kanban/`, `history/`, `workspaces/`) is generated by `/fw-init` and
`/fw-new-workspace`, never shipped.

## Layout

- `.claude-plugin/plugin.json` — plugin manifest (the identity of the deliverable)
- `commands/`, `skills/`, `scripts/` — plugin content (the deliverable itself)
- `standards/` — build-time staging for the TECH-187 docs audit; drains into
  `skills/` under the one-home-at-all-times rule; never ships

Install testing: the repo's `tools/Publish-ToLocalMarketplace.ps1` publishes this
plugin (alongside the old ones) to the shared local `dev-marketplace`.
